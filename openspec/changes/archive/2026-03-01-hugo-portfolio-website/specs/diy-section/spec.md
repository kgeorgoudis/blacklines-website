## ADDED Requirements

### Requirement: DIY section displays woodworking projects
The DIY section SHALL showcase woodworking and craft projects with descriptions and images.

#### Scenario: User browses DIY projects
- **WHEN** user navigates to the DIY section
- **THEN** a list of woodworking and craft projects is displayed

### Requirement: DIY projects include descriptions
Each DIY project entry SHALL include a title and descriptive text about the project.

#### Scenario: User reads project details
- **WHEN** user views a DIY project entry
- **THEN** project title and description are visible

### Requirement: DIY section supports project images
The DIY section SHALL display images for each project to showcase the final results.

#### Scenario: User sees project images
- **WHEN** user views a DIY project entry
- **THEN** associated images are displayed

### Requirement: DIY section provides project organization
Projects in the DIY section SHALL be organized chronologically or by category for easy browsing.

#### Scenario: User browses organized projects
- **WHEN** user views the DIY section
- **THEN** projects are presented in a logical order
